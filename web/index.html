Cycle

How a command will travel

  1. This page sends a command through MeshCore.
  2. LoRa carries it to the Heltec at the unit.
  3. The Heltec forwards it on ESP-NOW channel 1.
  4. The Waveshare accepts or refuses it. The Heltec does not drive the relays.

A start is ignored if the radio link is quiet, a required sensor is missing, or a thermal limit is already tripped. Stop is repeated until the controller answers. The touch screen can always stop the cycle.
